# The tool
[Switch to the terminal and run: lemonreel doctor --smoke]
LemonReel uses a single Lemonade Omni model. The language model writes the script, the image model
paints each scene, Kokoro reads it aloud, and Whisper listens back to make sure every name was said
correctly.
